0先记一句话原理（所有翻译的根）

一个箭头 A → B，同时表示两件事：

① A 是 B 的充分条件 —— 有 A 就一定有 B（有之必然）

② B 是 A 的必要条件 —— 没 B 就一定没 A（无之必不然）

命题类型含义白话标志词代表翻译方向
充分条件 有它就够了 如果…就…、只要…就…、凡是…都… 前 → 后（A→B）
必要条件 没有它不行 只有…才…、除非…否则不…、不…不…、…是…的前提/基础/关键 后 → 前（B→A）

判断方向的万能检测法（看到陌生关联词就这么干）

测法一：能不能改写成"如果 A，那么 B"且不改变原意？能 → 前推后 A→B。

测法二：能不能改写成"只有 A，才 B"且不改变原意？能 → 后推前 B→A。

测法三（必要条件类词的铁律）：谁必不可少，谁在箭头后。前提、基础、关键、保障、必须、需要、离不开、必不可少、不可或缺——这些词指向的那一项，永远放在箭头后面。

⚠ 关于"必须、离不开、需要"的定位

它们本身是必要条件的提示词，所以规律只有一条：它管着谁，谁就被推出（放箭头后）。

「上岸离不开听课」→ 听课是必要的，被推出 → 上岸→听课（这句是前推后）

「必须听课才能上岸」→ 听课是必要的，被推出 → 上岸→听课（这句是后推前）

两句话写法不同，箭头完全一样——方向不由句式决定，由"谁是必要条件"决定。

⚠ 头号考点：必要条件的位置陷阱（"是"字前后谁是大爷）

A 是 B 的前提／必要条件 → 前提是 A，A 被推出 → B → A

A 的前提／必要条件是 B → 前提是 B，B 被推出 → A → B

两句只差一个"的"字，箭头正好相反，这是历年真题最爱设的坑。

3专题：除非…否则…（否定一推一，两个都别背反）

处理方法只有一句：除非、否则 都是"否定词"，把其中一项打上"非"，推出另一项。

题干形式翻译（两种等价写法）说明
除非 A，否则不 B ¬A → ¬B
B → A		 最常考，等价于「只有 A 才 B」
除非 A，否则 B ¬A → B
¬B → A		 后面没有"不"，别自己加否定
A，否则 B（省略"除非"） ¬A → B
¬B → A		 同上一行
必须 A，否则 B ¬A → B
¬B → A		 "必须 A"＝"除非 A"
…，除非 A（后置式） ¬后件 → A 把"除非"从句尾搬到句首即可

背诵技巧

「除非 A 否则不 B」就是穿了马甲的「只有 A 才 B」！看到它就翻译成 B→A，与"只有才"共用同一套推理规则。

一旦原句里出现双重否定（如"除非 A，否则不不B"＝"除非 A 否则 B"），先消掉双否再翻译，别硬算。

4专题：且 / 或 / 要么 —— "否一推一"就在这里 高频

① 联言命题「A 且 B」

标志词：A 和 B ／ 既 A 又 B ／ 不但 A 而且 B ／ 虽然 A 但是 B ／ 不仅 A 还 B ／ A 也 B ／ 同时 ／ 并且 ／ 而且

规则内容
真假全真才真，一假即假
推理整体为真 → 可推出其中任意一项为真（A且B → A，A且B → B）
反向知道其中一项为假 → 整体为假；但知道一项为真 ≠ 整体为真

② 相容选言命题「A 或 B」← 你要的"否一推一"

标志词：A 或 B ／ 或者 A 或者 B ／ A 和 B 至少有一个 ／ 可能 A 也可能 B

规则内容
含义两者至少一个为真（可以两个都真）
真假一真即真，全假才假
否一推一¬A → B　¬B → A　（否定掉一项，另一项必然成立）
★不能肯一推一已知 A 为真，推不出 B 是真是假（这是选项里最常见的陷阱）

典型用法

「甲或乙进入决赛」为真 ＋ 已知「甲没有进入决赛」→ 乙进入决赛（否一推一）

「甲或乙进入决赛」为真 ＋ 已知「甲进入决赛」→ 乙的情况无法确定（肯一推不出）

⚠ 一对极易颠倒的选言：「至少有一个」vs「至多有一个」

「A、B 至少有一个」＝ A 或 B：允许都成立，不允许都不成立。

「A、B 至多有一个」＝ ¬A 或 ¬B（即"至少有一个不成立"）：允许都不成立，不允许都成立。

「恰好有一个」＝ 要么 A 要么 B：既不许都不成立，也不许都成立。

记法：「至少」管下限，「至多」管上限；把「至多有一个」翻成「至少有一个不」，就永远不会错。

③ 不相容选言命题「要么 A，要么 B」

标志词：要么…要么… ／ 不是 A 就是 B ／ 二者只能有一个成立 ／ 二者必居其一

规则内容
真假一真一假时才为真；同真或同假都为假
推理（四条全对）A → ¬B　B → ¬A　¬A → B　¬B → A
常见句式不是 A 就是 B ／ A 和 B 只能去一个 ／ 二者必居其一 ／ 二者只能有一个

⚠ 一定要分清

「要么 A 要么 B」能肯一推否一；「A 或 B」不能肯一推否一。选项中把两者混用，是官方设置的送命题。

5六大推理规则（翻译完怎么推）

规则公式口诀 / 用法
① 逆否等价 A→B ≡ ¬B→¬A 肯前必肯后，否后必否前；否前、肯后无必然结论（做题时可直接把"否前"和"肯后"的选项划掉）
② 递推（串珠） A→B，B→C ⟹ A→C 多个条件串成一条链；中间项不一致时，先用逆否把某句翻个面再对齐
③ 假言变选言 A→B ≡ ¬A 或 B 口诀"箭头变或者，前加非"；两个方向互转，等价题常用

712 个高频易错点（公考最爱反着考你）

#坑点正解与提醒
1只要…就… ⇄ 只有…才…只要就＝充分，前推后；只有才＝必要，后推前。一句话记："只要"很便宜（有它就行），"只有"很金贵（没它不行）。
2"A 是 B 的必要条件" ⇄ "A 的必要条件是 B"方向相反。用"谁必不可少，谁在箭头后"秒判。
3除非…否则不 / 除非…否则有无那个"不"字，箭头方向不同：有"不"→B→A；无"不"→¬B→A。写之前先把"不"字圈出来。
4必要条件句套用充分条件的推理规则翻译成 B→A 之后，仍然用"肯前必肯后、否后必否前"，即原句是肯后必肯前、否前必否后；原句肯前、否后都无必然结论。别凭语感。
5把"否前"或"肯后"当成能推出例：如果下雨就地湿；现在没下雨 → 地湿不湿不知道（可能洒水）。这是选项第一大陷阱。
6否定假言命题写错¬(A→B) ＝ A 且 ¬B，不是 A→¬B。少数"如果…那么…不成立"的题必考此点。
7德摩根"且/或"写反"并非既要 A 又要 B"＝¬A 或 ¬B；"并非 A 或 B"＝¬A 且 ¬B。
8"或"的肯一推一已知 A 或 B 为真、A 也为真 → B 无法确定，不能反推 ¬B（除非题面是"要么"）。
9因果当条件用"因为 A 所以 B"只是因果关系，不能逆否（¬B 推不出 ¬A，B 可能另有原因）；"越…越…"是共变关系，也不是推出关系；"即使 A 也 B"是让步句，只说明 B 不受 A 影响，不是条件句。判断不了的句子，先试着套"如果…那么…/只有…才…"，套不上就别翻。
10"有的"与"所有"互推"有的 A 是 B"推不出"所有 A 是 B"，也推不出"有的 A 不是 B"；只有"所有 A 是 B"才可反向对应"有的 B 是 A"。
11递推时中间项对不上如 ①A→B ②¬B→C ③C→D：先把①逆否成 ¬B→¬A，才能和②串成 ¬C→B→A 或用 ¬B 作桥。中间项必须字面完全一致（含否定符号）。
12"必须 / 需要 / 离不开"的位置误判看见这些词就找被它修饰的结果：结果在前，条件在后 → 结果 → 条件。永远不要按词序硬翻。

8例题实战（每题都是考过的经典坑）

例1（只要 / 只有 辨析）

句①：只要努力，就能上岸。　句②：只有努力，才能上岸。

已知小明没有努力，分别能推出什么？

①翻译：努力→上岸。"没努力"是否前 → 无必然结论。

②翻译：上岸→努力。"没努力"是否后 → 必然推出"没上岸"。

例2（必要条件位置陷阱）

甲：大力宣传法制是推进依法治国的前提。　乙：推进依法治国的必要条件是大力宣传法制。　丙：大力宣传法制的前提是推进依法治国。

甲：前提是宣传 → 依法治国 → 宣传法制

乙：必要条件是宣传 → 依法治国 → 宣传法制

丙：前提是依法治国 → 宣传法制 → 依法治国（因为"的"的位置变了，方向反转）

例3（除非…否则）

老王："除非你在今天之内按合同要求支付货款，否则我们法庭上见。"
下列哪项含义与之不同？

A. 只有你今天支付货款，老王才不会告你。

B. 如果你今天支付货款，那么老王不会告你。

C. 如果你今天不支付货款，那么老王就会告你。

题干＝"除非 A 否则 B" → ¬支付 → 法庭见（亦 ¬法庭见 → 支付）。

A：只有才 → ¬法庭见→支付 ✔ 一致。　C：¬支付→法庭见 ✔ 一致。

B：支付→¬法庭见，是否前推否后 → 推不出，答案选 B。

例4（否定假言命题）

"如果下雨，那么地湿"这句话为假，说明了什么？

¬(A→B) ＝ A 且 ¬B → 下雨 且 地没湿。

选项若写"如果下雨则地不湿""地湿说明没下雨"，都是错的。

例5（否一推一 / 肯一推不出）

已知"甲或乙进入决赛"为真。

（1）若又知甲没进 → 否一推一 → 乙进。

（2）若又知甲进 → 乙不确定（可能都进了）。

（3）若题干换成"要么甲进，要么乙进" → 甲进 必然推出乙不进。

例6（德摩根 + 递推）

①只有通过笔试，才能进入面试。②如果通过笔试，就必须参加体检。

①：进面试 → 通过笔试　②：通过笔试 → 体检

串联：进面试 → 通过笔试 → 体检；逆否：¬体检 → ¬通过笔试 → ¬进面试

若某选项说"通过笔试就一定进面试" → 肯前推肯后，排除。

例7（二难推理 / 归谬）

①如果小张去，那么小李去。②如果小张不去，那么小李也去。

A→C 且 ¬A→C ⟹ C 必然成立：无论小张去不去，小李都去。

例8（所有 / 有的）

"并非所有公务员都通过了考试。"

＝ 有的公务员没有通过考试（不是"所有公务员都没通过"）。

例9（假言变选言）

"如果下雨，比赛就取消"还可以等价地写成什么？

A→B ≡ ¬A或B → 不下雨，或者比赛取消（两者至少成立一个）。

错法：写成"下雨或者比赛取消"——把前件的"非"忘了加。

例10（至少 / 至多）

"甲、乙至多有一人获得名额"意味着什么？

＝"甲、乙至少有一人没拿到"＝ ¬甲 或 ¬乙：允许两人都没有，不允许两人都有。

对比："至少有一人获得"＝甲或乙：允许两人都有，不允许都没有。两个字之差，方向完全相反。

9口诀背诵版（考前 30 秒扫一眼）

❶ 如果就，前推后；只要就，也是前推后。

❷ 只有才，后推前；不…不…、除非…否则不、没有…就没有，统统后推前。

❸ 谁必不可少，谁在箭头后（前提、基础、关键、必须、离不开）。

❹ 除非否则，否一推一；有"不"翻成只有才。

❺ 或关系，否一推一；且关系，一假即假。

❻ 肯前必肯后，否后必否前；否前肯后，一律没结论。

❼ 箭头变或者，前面加个非（A→B ＝ ¬A或B）。

❽ 且或互换，逐项加非（德摩根）。

❾ 如果就为假 ＝ 前真后假。

❿ 因果、越…越，不是条件，别乱翻。

解题四步走

①看提问：出现"可以推出 / 不能推出 / 由此能推出"＋题干有逻辑关联词 → 判定为翻译推理。

②逐句翻译：充分写 A→B，必要写 B→A，"且/或/要么"单独标出。

③串珠：把有共同项的句子连成链，中间项对不上先用逆否翻面。

④验选项：肯前 ✔ 否后 ✔；否前 ✘ 肯后 ✘；再看"且或"和"所有有的"有没有被偷换。

10专题：所有 / 有的（集合命题四句话）高频

题干里出现「所有、凡是、任何、每一个、有的、有些」时，先把它们翻成箭头的模样，再照常推理。

句式含义与翻译矛盾命题（非它）
所有 A 都是 B全部 A 都在 B 里 → A→B有的 A 不是 B
所有 A 都不是 BA 与 B 全无交集 → A→¬B有的 A 是 B
有的 A 是 B至少一个 A 同时是 B（不排除全部）所有 A 都不是 B
有的 A 不是 B至少一个 A 不在 B 里所有 A 都是 B

换位规则（该换的才能换，选项最爱在这里挖坑）

原命题可以换位成说明
所有 A 都是 B有的 B 是 A只能换成「有的」
所有 A 都不是 B所有 B 都不是 A全称否定可自由换位
有的 A 是 B有的 B 是 A特称肯定可自由换位
有的 A 不是 B不能换位推不出「有的 B 不是 A」

⚠ 三条红线

① 「有的 A 是 B」推不出「有的 A 不是 B」，也推不出「所有 A 是 B」；反向同样不行。

② 「所有 A 都 B」不能倒写成「所有 B 都 A」，只成立「有的 B 是 A」。

③ 否定要"点到为止"：否定「所有」得到「有的…不…」；否定「有的」得到「所有…都不…」。

与条件句联动

「所有 A 都 B」就是 A→B，「所有 A 都不是 B」就是 A→¬B：逆否、递推照用不误。

例：「所有参加者都提交了材料」＋「小周没有提交材料」→ 小周没有参加（否后必否前）。

例：「并非有的动物不会游泳」＝ 所有动物都会游泳（特称否定的矛盾是全称肯定）。
