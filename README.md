## 一、项目概览

本项目面向公务员考试（国考 / 省考 / 选调生）《行政职业能力测验》中的**判断推理 · 翻译推理与形式逻辑**模块，结合公开行测知识体系与 GitHub 开源真题库（2016–2026 国省考真题句式与考点模型）重新命制与整理，提供**刷题训练 + 全量题库检索 + 速查手册 + 本地错题本**一体化学习体验。

| 维度 | 数据与配置 |
| --- | --- |
| **题库总量** | **360 道**（全部含 4 个选项、唯一正解、逐项错因深度解析） |
| **三大题型** | 句子→翻译（165 题） · 翻译→句子（110 题） · 条件小推理（85 题） |
| **考点分类** | **20 大高频考点**（全覆盖假言、选言、联言、集合、模态、真假、搭桥、诗文平行结构） |
| **速查手册** | **0～13 共 14 节专题** + **15 道经典真题同源例题精讲** |
| **交互功能** | 按题型/考点自由组卷 · 60s/90s/不限时倒计时 · 本地持久化错题本 · 全量题库关键词搜索 · 逐题回顾 |

## 三、主要功能说明

1. **刷题模式**：支持按 3 种题型、20 个考点自由组合筛选，支持 `10 / 20 / 30 / 50 / 100 / 全部做完` 6 档题量，以及 `60秒 / 90秒 / 不限时` 3 档计时；支持键盘快捷键（`A/B/C/D` 或 `1/2/3/4` 作答，`Enter`/`Space` 下一题）。
2. **本地错题本**：作答错误或超时的题目会自动收录至浏览器本地 `localStorage` 错题本；点击「专项练错题」可针对薄弱题反复强化，答对后自动移出错题本。
3. **全量题库检索**：顶部切换至「题库」标签，可按关键词（如“除非”“至多”“模态”“真假”“龙城”“搭桥”）、题型、考点实时筛选全部 360 道题目，点击任意题目即可展开/收起答案与解析。
4. **全关联词速查表**：涵盖 0～13 共 14 个核心章节与 15 道典型例题，手机端自动将宽表格转换为高可读性卡片视图。
